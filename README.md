# Work Order Tracker

A simple web app for creating, assigning, and tracking work orders, built for lab and maintenance teams.

## Planned features
1. Create a work order (title, description, location, priority, due date)
2. Assign it to a person and track status (Open, In Progress, Done)
3. Search and filter by status, priority, or assignee
4. Dashboard showing open, overdue, and completed counts
5. Export work orders to CSV for reports

## Tech
HTML, CSS, JavaScript, and SQL (planned)

## Status
Just getting started. Building one feature at a time.
